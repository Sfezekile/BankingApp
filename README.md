# Banking App

A simple web-based banking application interface built with HTML, CSS, and JavaScript. This project provides a user-friendly frontend for viewing account balance, recent transactions, and performing basic banking actions like sending money.

## Features

- **User Login**: Secure login page to access the account.
- **Account Overview**: Display total balance with toggle to hide/show.
- **Recent Transactions**: List of recent transactions with details.
- **Send Money**: Interface to send money to other accounts.
- **Quick Actions**: Grid of quick action buttons for common tasks (e.g., Pay Bills, Top Up, etc.).
- **Responsive Design**: Mobile-friendly layout using CSS Flexbox and Grid.

## Technologies Used

- **HTML5**: Structure of the web pages.
- **CSS3**: Styling with custom properties (CSS variables) for colors and fonts.
- **JavaScript**: Basic interactivity, such as balance toggle and action alerts.
- **Remixicon**: Icon library for UI elements.
- **Google Fonts**: Libre Baskerville font for headings.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/banking-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd banking-app
   ```
3. Open `main.html` in your web browser to start the application.

No additional dependencies or build steps are required, as this is a static web app.

## Usage

- **Login**: Start by opening `login.html` and entering credentials (note: this is a frontend-only demo, no actual authentication).
- **Main Dashboard**: View balance, transactions, and use navigation.
- **Send Money**: Click the "Send" button or navigate to `send.html` to initiate a transfer.
- **Navigation**: Use the bottom navigation bar to switch between sections.
